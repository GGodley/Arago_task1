Over time (model, quasi-optimal schedule)

Matrix units start after the first tile lands (4 ticks) and finish with the last save. Memory is the least the schedule needs: running sums plus tiles in flight (Little's law).

Model: 64×64 tiles; 1 tick = 128 cycles; LOAD/SAVE 4 ticks, COMPUTE/ACC 1 tick. Speed P means the job finishes as fast as P matrix units kept busy: target T = 8 + ⌈W / P⌉ ticks, so Nm = ⌈W / (T − 8)⌉. For each memory size the optimizer tries every block and panel tiling, keeps those that fit (running sums + in-flight tiles ≤ S) and have enough independent work for Nm units, and picks the one needing the fewest DMA units.
